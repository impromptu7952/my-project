# Script: Sytë, hunda, goja

**Slug:** `trupi-syte-hunda-goja`  
**Age band:** 1-3  
**Type:** body_move  
**Presenters:** lumi, pip  
**Target duration:** ~200s  
**Vocabulary:** sytë, hunda, goja

## Learning goals
- Point to facial features
- Gentle touch practice

## Co-play tip (parent)
Pauzoni videon pas çdo pyetjeje. Përsëriteni fjalët me objekte reale në dhomë.

## Script (standard literary Albanian, parentese)

### 1. Hello ritual [~30s]
**LUMI** *(to camera, wave)*  
Përshëndetje, miq të vegjël!  
Unë jam Lumi.  
[PAUSE 4s]  
A thua bashkë sot?  
[PAUSE 5s]  

**PIP**  
Pip-pip!  

### 2. Teach block [~66s]

**LUMI** *(show prop for «sytë» / eyes)*  
Ja… **sytë**.  
[GESTURE]  
[PAUSE 5s]  
A thua: sytë?  
[PAUSE 6s]  
Shumë mirë!  

**LUMI** *(show prop for «hunda» / nose)*  
Ja… **hunda**.  
[GESTURE]  
[PAUSE 5s]  
A thua: hunda?  
[PAUSE 6s]  
Shumë mirë!  

**LUMI** *(show prop for «goja» / mouth)*  
Ja… **goja**.  
[GESTURE]  
[PAUSE 5s]  
A thua: goja?  
[PAUSE 6s]  
Shumë mirë!  

### 3. Interactive / song [~50s]
**LUMI**  
Ku është… sytë?  
[PAUSE 6s]  
Bravo!  

### 4. Recap + goodbye [~25s]
**LUMI**  
Sot thamë: sytë, hunda, goja.  
Shumë mirë sot!  
[WAVE]  
Mirupafshim, deri herën tjetër!
